Mu Anchor Viewer Help

会話を「読み返せる記録」から「引き継ぐ記憶」へ整えるために

このビューワーは、会話を静かに見返しながら、「残したいもの」「振り返りたいもの」に印をつけて整理するための道具です。
まずは「残すべき会話」と「見直すべき会話」を分けるだけでも、十分に価値があります。
事前準備は一切不要です。

このビューワーでできること

  • 会話を検索し、分類し、まとまりごとに見直せます。
  • 会話単位で「お気に入り」「タグ」「分析グループ」を付けられます。
  • メッセージ単位・行単位で Good / Bad を残せます。
  • 重要箇所にしおりとメモを付け、後からすぐに戻れます。
  • 整理した状態を viewer_state.json として保存し、次回も続きから作業できます。

最初の使い方（3分）

  1. output フォルダを選択して会話一覧を読み込みます。
  2. 左の一覧から会話を開き、まずは「お気に入り」か「タグ」を1つ付けます。
  3. 特に残したい返答へ Good、改善したい返答へ Bad を付けて保存します。
  4. たとえば「この言い回しが好き」「この応答テンポが心地よい」と感じたときは Good、「少しズレていた」「もう少し違う反応が欲しかった」なら Bad を付けてみてください。

この3手順だけで、次に見返すべき会話がはっきりしてまいります。量が多いときほど、最初は粗く仕分けるのがおすすめです。

整理の進め方（おすすめ）

  1. まず「お気に入り」で、残したい会話だけを拾います。
  2. 次に「タグ」で用途を付けます（例: 日常, 執筆, 相談, 要検討）。
  3. 必要に応じて「分析グループ」で人物・テーマ別に束ねます。
  4. 最後に Good / Bad で応答品質を印付けし、見直し対象を明確にします。

「全部を完璧に整理しよう」とせず、ひと巡りごとに粒度を上げると、負担なく続けられます。

Good / Bad の考え方

  • メッセージ右上の Good / Bad は、その返答全体への印です。
  • 行の右端に出る Good / Bad は、その一行だけへの印です。
  • 迷うときは「あとで再利用したいか」を基準にすると判断しやすくなります。

この記録は、あとで会話を再設計するときの指針になります。短い印でも、積み重なるほど効いてきます。

保存と引き継ぎ

  • 整理状態は viewer_state.json に保存されます。
  • 別日のエクスポートを開いた際は、「引き継ぐ」「引き継がない（完全新規）」を選べます。
  • 初めて見るデータなら「引き継がない（完全新規）」で問題ありません。

途中で止めても大丈夫です。状態を保存しておけば、次回は同じ場所から落ち着いて再開できます。

このビューワー単体の価値

まだ分析ツールを使わない段階でも、会話を「分類」「評価」「再訪可能な形」に整えるだけで、十分に意味があります。 散らばった会話が、判断できる記録に変わること。それ自体が、次の一歩を軽くします。

控えめなご案内

実際にモデルのお引越しを進める段階になった方向けに、整理結果を分析する analyzer と、移行先向けの指示文を整える prompter を販売予定です。 必要になったときにだけ、ご検討いただければ十分です。
